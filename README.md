# Cap Fahmy — website

Cinematic wellness–performance site for **CAP FAHMY**.  
Slogan: *Strong Today. Independent Tomorrow.*

## Run locally

Open `index.html`, or:

```powershell
Start-Process index.html
```

## Structure

| Path | Role |
| --- | --- |
| `index.html` | Full homepage (storytelling sections) |
| `onboard.html` | Waiver-gated assessment intake |
| `styles.css` | Design system + components |
| `app.js` | Nav, i18n, compare, library, intake |
| `i18n.js` | EN / AR copy |
| `playlists.json` | Exercise library data |
| `assets/` | Photos / hero media placeholders |
